📰 NewsZone

NewsZone is a modern React web application that fetches and displays the latest news articles using the NewsAPI.
It provides users with real-time news updates across different categories such as Technology, Business, Sports, Health, and more.


🚀 Features

Built with React.js

Fetches news from NewsAPI

Categorized news sections (e.g., Technology, Sports, Business)

Responsive design for desktop and mobile

Simple and clean UI

🛠️ Tech Stack

Frontend: React.js, React Router

API: NewsAPI.org

Styling: CSS 

HTTP Client: Fetch API
